HOW IT WORKS:
=============

1. render_lerf_mask.py
   - Uses GroundingDINO to detect objects matching text
   - Uses SAM to segment those objects
   - Computes IoA (Intersection over Area) with 3D object masks
   - Saves the matching object IDs to JSON

2. edit_by_text.py
   - Reads the selected_obj_ids.json
   - Creates removal config with those IDs
   - Runs the removal script
   - (Optional) Runs inpainting
