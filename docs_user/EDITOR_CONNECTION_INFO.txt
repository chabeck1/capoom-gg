STEP 2: INSTALL SIBR VIEWER (ONE-TIME SETUP ON YOUR MAC)
════════════════════════════════════════════════════════════════════

If you haven't installed the SIBR viewer yet:

# Clone the Gaussian Splatting repository
git clone https://github.com/graphdeco-inria/gaussian-splatting --recursive
cd gaussian-splatting

# Build the SIBR viewers
cd SIBR_viewers
cmake -Bbuild . -DCMAKE_BUILD_TYPE=Release
cmake --build build -j8 --target install

This will take 10-15 minutes the first time.

════════════════════════════════════════════════════════════════════
STEP 3: CONNECT THE EDITOR
════════════════════════════════════════════════════════════════════

Once SSH tunnel is running and SIBR is built:

cd gaussian-splatting/SIBR_viewers
./install/bin/SIBR_remoteGaussian_app --port 6009

A window will open showing the bear scene in real-time!

🔧 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════

❌ "Connection refused" in SIBR viewer
   → Make sure SSH tunnel is running
   → Check: lsof -i :6009 on your Mac

❌ Port 6009 already in use
   → Kill existing process: kill $(lsof -t -i:6009)
   → Or use different port

❌ SIBR viewer won't build
   → Install dependencies: brew install cmake glfw glew
   → Check SIBR documentation

❌ Can't see anything in viewer
   → Wait 30-60 seconds for model to load
   → Check the log file for errors
   → Try pressing R to reset view
