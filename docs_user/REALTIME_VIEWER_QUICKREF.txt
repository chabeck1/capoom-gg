═══════════════════════════════════════════════════════════════════

📋 STEP 1: Start Viewer on ARC @ GLC
────────────────────────────────────────────────────────────────────
On Great Lakes login node:

    sbatch slurm_jobs/viewer_job.slurm
    ./scripts_user/setup_viewer_tunnel.sh

This will show you the SSH tunnel command and compute node.

📋 STEP 2: Setup SSH Tunnel from Your Mac  
────────────────────────────────────────────────────────────────────
Copy the mac_tunnel.sh script to your Mac:

    scp chabeck@greatlakes.arc-ts.umich.edu:~/gaussian-grouping/scripts_user/mac_tunnel.sh ~/

Then run (replace with actual compute node):

    chmod +x ~/mac_tunnel.sh
    ~/mac_tunnel.sh gl3001.arc-ts.umich.edu

Keep this terminal open while using the viewer!

📋 STEP 3: Connect Viewer Client
────────────────────────────────────────────────────────────────────

OPTION A: SIBR Viewer (Recommended)
    
    # One-time setup on your Mac:
    git clone https://github.com/graphdeco-inria/gaussian-splatting
    cd gaussian-splatting/SIBR_viewers
    cmake -Bbuild . -DCMAKE_BUILD_TYPE=Release
    cmake --build build -j8 --target install
    
    # Every time you want to view:
    ./install/bin/SIBR_remoteGaussian_app --port 6009

OPTION B: SuperSplat (View-Only, No Real-Time)
    
    # Download the .ply file
    scp chabeck@greatlakes.arc-ts.umich.edu:~/gaussian-grouping/output/bear/point_cloud/iteration_30000/point_cloud.ply ~/
    
    # Upload to https://playcanvas.com/supersplat/editor

Check viewer status:
    squeue -u chabeck -n gg_viewer
    tail -f logs/viewer_*.log

Stop the viewer:
    scancel <job_id>

Monitor GPU usage:
    ssh <compute_node>
    nvidia-smi -l 1

Test tunnel connection (on Mac):
    nc -zv localhost 6009

═══════════════════════════════════════════════════════════════════
    TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

❌ "Connection refused"
   → Check SSH tunnel is running
   → Verify compute node name is correct
   → Check viewer server started: tail logs/viewer_*.log

❌ "Port already in use" 
   → Kill existing process: kill $(lsof -t -i:6009)
   → Or use different port (edit scripts)

❌ Viewer job won't start
   → Check GPU availability: squeue -p spgpu
   → Verify conda environment: conda env list

❌ Slow/laggy performance
   → Check network latency: ping greatlakes.arc-ts.umich.edu
   → Reduce resolution in viewer settings
   → Use simpler scene for testing

═══════════════════════════════════════════════════════════════════
    SCENE EDITING AFTER VIEWING
═══════════════════════════════════════════════════════════════════

Extract objects from viewed scene:
    python capoom_street_furniture.py --mode extract \
        --scene output/bear --objects "bear"

Add objects to new locations:
    python capoom_street_furniture.py --mode add \
        --scene output/bear --objects bear \
        --position 5.0,0.0,1.5 --rotation 0,45,0 --scale 1.0

Remove objects:
    python edit_object_removal.py -m output/bear \
        --iteration 30000 --object_id <id>
