========================================
TEXT-BASED EDITING QUICK REFERENCE
========================================

❌ DON'T run on login node (no GPU):
   python edit_by_text.py --scene output/bear --remove "trees"

✅ DO use SLURM (has GPU):
   sbatch edit_by_text_job.slurm output/bear "trees"

========================================
EXAMPLES
========================================

# Remove trees only
sbatch edit_by_text_job.slurm output/bear "trees"

# Remove bear (10-15 minutes)
sbatch edit_by_text_job.slurm output/bear "bear"

# Remove bear AND inpaint holes (1-2 hours)
sbatch edit_by_text_job.slurm output/bear "bear" --inpaint

# Remove multiple objects
sbatch edit_by_text_job.slurm output/bear "trees;rocks;grass"

========================================
CHECK STATUS
========================================

squeue -u $USER                    # See running jobs
tail -f logs/edit_text_*.log       # Watch progress

========================================
VIEW RESULTS
========================================

# After removal only:
ls output/bear/train/ours_object_removal/renders/

# After inpainting:
ls output/bear/train/ours_object_inpaint/renders/

# Download via VSCode and view PNGs

========================================
WHY SLURM?
========================================

The login node doesn't have:
- NVIDIA GPU (needed for GroundingDINO + SAM)
- CUDA drivers (needed for PyTorch GPU ops)

SLURM allocates a GPU node automatically!
