📡 Connection Setup Required

To use this viewer, you need to:

  1. Start the viewer server on Great Lakes:
    sbatch slurm_jobs/viewer_job.slurm
  2. Set up SSH tunnel from your Mac:
    ssh -L 6009:<compute_node>:6009 chabeck@greatlakes.arc-ts.umich.edu
  3. Keep the SSH tunnel terminal open
  4. Click "Connect" above

📄 See REALTIME_VIEWER_GUIDE.md for detailed instructions.
